# 通用参赛作品说明书架构（ distilled framework ）

> 从《知行读书 · 参赛作品说明书.docx》中提取的可复用骨架，面向任意参赛项目（AI / 硬件 / 社创 / 设计均可套用）。
> 来源：`d:\ai\latex\蒸馏区\` 下的 `.tex` / `.docx` 蒸馏产物

---

## 1. 顶层结构（6 + 1 模式）

| 编号 | 章节 | 作用 | 必选 |
|------|------|------|------|
| 0 | 引言 | 200-300 字，三段式：为什么做 → 回答什么问题 → 文档结构 | 必选 |
| 1 | 项目概述 | 电梯演讲 + 是什么/解决什么/怎么做 + 评审标准对标概览 | 必选 |
| 2 | 详细介绍 | 核心主体：痛点、功能、创新、架构、重点专章 | 必选 |
| 3 | 附言 | 感性补充：工具经验、个人想法、竞品差异、评审详细对标、应用价值、未来规划 | 推荐 |
| 4 | 数据来源与合规说明 | 数据矩阵 + API / AI / 数据安全 / 开源声明 | 必选（涉及数据/ API 的项目） |
| 5 | 使用教程与常见问题解答 | 系统要求、安装、FAQ | 推荐（有可运行产物时必选） |
| 6 | 致谢 | 四段式致谢 + 情怀收尾 | 必选 |

---

## 2. 第 1 章：项目概述（固定三段）

1. **一句话定位**（30-50 字电梯演讲）
   - 要素：是什么 + 面向谁 + 区别性
2. **是什么 / 解决什么 / 怎么做**
   - 用 `\subhead{是什么}` / `\subhead{解决什么}` / `\subhead{怎么做}` 格式
3. **评审标准对标概览**
   - 表格：`tabularx{\textwidth}{>{\bfseries\color{MainColor}}l X}`
   - 行：创新性与创意度 / 技术实现与复杂度 / 实用价值与落地性 / 用户体验与交互设计

---

## 3. 第 2 章：详细介绍（模块化组装）

### 3.1 解决的问题
- 先 1 段引出"现有工具链是断裂的"
- 再放 **痛点 × 现状 × 解决方案** 三列表格（`tabularx{\textwidth}{>{\bfseries}l X X}`）
- 建议 6-8 行

### 3.2 核心功能全景（二选一或组合）
- **开放能力深度集成**（如果项目依赖外部平台 Skill/API）
  - 放 Skill 接口分析表：接口 / 开放能力 / 挖掘方式
- **N 大核心功能模块详情**
  - 表格：`# / 模块 / 路由 / 核心能力`
  - 配 2-3 张主界面截图（`0.32\textwidth` 三宫格或 `0.48\textwidth` 双栏）

### 3.3 N 大核心创新点（3-5 个）
- 每个创新点一节（`\subsection`）
- 结构：引出段 → 工程细节（`itemize` 或表格） → `\subhead{效果}` 总结
- 至少 1 个创新点要配数据表（预算/性能/量化）

### 3.4 整体技术架构（软件/硬件项目必选）
- 系统架构总览图（大图，`0.95\textwidth`）
- 关键技术细节（可选小图或表格）
- 数据库/数据表设计（如有）
- 技术栈层次表：`层 / 选型 / 说明`

### 3.5 重点专章：核心引擎/算法/机制（灵魂模块，单独突出）
- 用 1 张流程图 + 1 张时序图（如有）
- 每一步设计细节（`\subhead{① xx}` 格式）
- 性能画像表：`步骤 / 延迟 / 类型`

## 8. 通用占位策略

| 标记 | 含义 | 使用场景 |
|------|------|----------|
| `{占位}` | 短句替换（1-2 行） | 一句话定位、效果总结、简短说明 |
| `{引文占位}` | 段落替换（3-5 行） | 引出段、背景描述、机制说明 |
| `{摘要占位}` | 大段替换（300-500 字） | 摘要、致谢、个人想法 |
| `\subhead{xxx}` | 题目小标题（黑体 11pt 加粗） | 小节要点、FAQ 问题 |

## 9. 表格/图片规范

### 表格
- 环境：`\begin{table}[htbp]` + `\begin{tabularx}{\textwidth}{...}`
- 列格式：`>{\bfseries}l X X` 或 `c >{\bfseries}l l X`
- 必须：`\toprule / \midrule / \bottomrule`（booktabs）
- 必须：`\caption{...}` + `\label{tab:xxx}`
- 标题在表格**下方**

### 图片
- 环境：`\begin{figure}[htbp]` + `\centering` + `\includegraphics[width=...]{figures/img_NNN.png}`
- 标题在图片**下方**
- 网格排版用 `\hfill` + `\\[6pt]`
- 占位路径统一用 `figures/img_NNN.png`

| 元素 | 规范 |

## 12. 复用清单（快速上手新项目）

1. 复制整个 `蒸馏区/` 为新项目目录
2. 在 `.tex` 顶部配置区修改：
   - `\projectType`（项目类型）
   - `\reviewDims`（评审维度）
   - 各 `\show...` 开关（按需裁剪章节）
3. 改 `.tex` 作品信息区（标题/作者/单位/日期/项目）
4. 把图片按 `figures/img_NNN.png` 放入 figures/ 目录
5. 替换所有 `{占位}` 文字
6. 运行 `.\build.ps1` 编译
