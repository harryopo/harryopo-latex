[P033] [Heading 2] ### [Heading 2] 2.3  五大核心创新点  {font=Times New Roman, size=14.0pt, bold=True}
[P034] [Heading 3] ### [Heading 3] 创新点 1：方法论自动注入 Agent（行业首创）  {font=Times New Roman, size=12.0pt, bold=True}
[P035] [Normal] 传统 AI 阅读工具只能基于用户输入的上下文生成回答，无法主动调用书中的结构化方法论。知行读书引入 MethodologyContextBuilder：
[P036] [Normal] 从书籍对应的 methodology 表检索相关方法论
[P037] [Normal] 按意图相关性排序后注入 system prompt
[P038] [Normal] AI 回答时自动引用具体章节与方法论名称
[P039] [Normal] 对话结束后回调更新掌握度（mastery level），实现"用一次、深一层"
[P040] [Normal] 效果：回答不再泛泛而谈，而是基于书籍知识框架给出可操作建议，并持续追踪用户对每条方法论的掌握程度。用户还可将任意方法论一键导出为Skill 文件，实现"读书 → 方法论 → Skill → AI 实践"的知识二次流通。
[P041] [Heading 3] ### [Heading 3] 创新点 2：5 维 ContextBuilder（预算制懒加载）  {font=Times New Roman, size=12.0pt, bold=True}
[P042] [Normal] 为降低 Token 消耗并提升回答相关性，构建 5 个上下文维度，按优先级懒加载：
[P043] [Normal] 表5：ContextBuilder详情图
[P044] [Normal] 三条硬规则：预算不足时低优先级自动跳过；每个构建器独立失败不拖垮整体（fail-soft 柔性容错）；超预算截断并显式标记。实测对比全量加载方案，50 次中等复杂度对话平均节省 Token（AI 按文本量计费的单位） 33%-55%，中位数 38%。
[P045] [Heading 3] ### [Heading 3] 创新点 3：FSRS v5 (DSR) 间隔复习 · 同源科学记忆引擎  {font=Times New Roman, size=12.0pt, bold=True}
[P046] [Normal] 不是自己拍脑袋写的"复习提醒"，而是直接集成 ts-fsrs 5.4.1（open-spaced-repetition 官方实现，与 Anki 23.10+ 同一算法）：
[P047] [Normal] FSRS v5 DSR 模型：19 组标准权重（DSR = 难度-稳定性-可提取性，描述记忆状态的三个变量），基于海量真实复习记录训练，记忆保持率比传统算法（SM-2、Leitner 卡盒法）高 20-30%，有效避免 "ease hell"（简易度地狱：传统算法中卡片越复习间隔越短的恶性循环）
[P048] [Normal] 零手工成本：微信读书划线自动生成卡片——这是 Anki 用户梦寐以求的"自动喂卡"
[P049] [Normal] repeat() 预览：评分前即可看到 4 种评分各自的未来间隔
[P050] [Normal] 数据互通：卡片 schema（数据结构定义）与 Anki 对齐，可导出到 Anki 跨平台复习
[P051] [Normal] 零破坏升级：从自实现引擎切换到官方库时，通过适配层做到对外 API 100% 兼容，38 个引擎测试全绿
[P052] [Heading 3] ### [Heading 3] 创新点 4：本地优先架构 · 数据主权还给用户  {font=Times New Roman, size=12.0pt, bold=True}
[P053] [Normal] 全部核心数据在本地：sql.js（SQLite WASM，即嵌入应用内部运行的数据库引擎，无需额外安装）16 张表，3 秒防抖持久化 + 退出强制保存
[P054] [Normal] RAG 也在本地：RAG（检索增强生成：先从你的笔记里检索相关内容，再让 AI 据此回答）采用 Vectra 纯 TypeScript 向量索引，语义搜索不出本机；向量检索失败自动回退 SQLite 关键词搜索
[P055] [Normal] 密钥系统级加密：Electron safeStorage（调用操作系统自带的加密能力）加密存储 API Key，仅主进程可解密
[P056] [Normal] AI 可热切换：火山引擎 / DeepSeek / OpenAI / Anthropic /任意切换，请求直连不过中转
[P057] [Normal] 零遥测：不含任何分析/追踪/广告 SDK
[P058] [Normal] 离线可用：除同步和 AI 对话外，复习/笔记/卡片/词典全部离线可用
[P059] [Heading 3] ### [Heading 3] 创新点 5：ECDICT 离线词典 + 语境化英语学习  {font=Times New Roman, size=12.0pt, bold=True}
[P060] [Normal] 内置从开源 ECDICT（开源英汉词典数据库）提取的 13.6 MB JSON 词典（近 6 万词条）
[P061] [List Paragraph] 悬停查词 O(1) 内存缓存（毫秒级即时响应）
[P062] [List Paragraph] 支持动词时态、名词单复数等 6 类词形变化还原（动词时态、名词单复数、形容词比较级、副词变形、-ing 形式、-ed 形式）
[P063] [List Paragraph] 配合每日英文外刊（RSS 订阅源聚合 + AI 翻译对照 + CET-4/6/考研三级难度）
[P064] [List Paragraph] 实现"在真实语境中学单词"，右键加入生词本后由 FSRS 算法统一安排复习

[P097] [Normal] ③ 难度自适应（state-tracker）——基于会话状态机的 Bloom 认知层级调整：
[P098] [Normal] 连续答对 3 次 → 升层级（AI 提问变难）

[P108] [Heading 3] ### [Heading 3] 2.5.3  对话后自动学习（闭环的关键）  {font=Times New Roman, size=12.0pt, bold=True}
[P109] [Normal] 每轮对话完成后自动执行三件事（用户零感知）：
[P110] [Normal] updateConceptMastery —— 更新本轮涉及概念的掌握度
[P111] [Normal] extractMemoriesFromConversation —— 提取偏好/事实/反馈三类长期记忆入库
[P112] [Normal] updateMethodologyMastery —— 若引用了方法论，更新其掌握度
[P113] [Normal] 这让 Agent 拥有了"成长性"：记忆系统喂给下一轮的 MemoryContextBuilder，掌握度喂给难度自适应和提示组装——系统越用越懂你，形成个性化飞轮。

[P158] [Heading 2] ### [Heading 2] 3.2  个人想法  {font=Times New Roman, size=14.0pt, bold=True}
[P159] [Normal] 我自己到底得到了什么？以下是我作为第一个用户的真实自述，也是我最想对评委说的一段话——它回答"这个产品到底能干什么"。
[P160] [Normal] 我最大的感受，是第一次真正与一个"懂我笔记"的 AI 对话。它知道我在哪本书的哪一页划了线，知道我反复关注的是什么主题。问它问题时，它不是给我一段百科全书式的泛泛而谈，而是引用我自己划过的那句话、接着我自己的思考往下追问。这种体验和 ChatGPT 完全不同——通用 AI 面前我是陌生人，知行读书里的 AI 是陆续读完了我所有笔记的老朋友。
[P161] [Normal] 一个具体的例子：《被讨厌的勇气》怎么改变了我处理人际关系的方式。
[P162] [Normal] 我的知识卡片和方法论库里，沉淀最多的是个人心理方向的内容。读《被讨厌的勇气》时，知行读书从我的划线里自动提炼出了几条方法论：课题分离（分清"这是谁的课题"，别人如何评价你是别人的课题）、目的论（不是"因为过去所以现在"，而是"为了某个目的选择了现在"）、横向关系（不评价、不比较，把人当伙伴而非对手）——每条都带着触发场景标签，比如"在意别人看法时"、"人际冲突时"。
[P163] [Normal] 真正的变化发生在读完之后。以前我接了别人的请求不好意思拒绝，事后又内耗很久；现在遇到这种时刻，我会想起方法论库里那张"课题分离"卡——拒绝之后对方怎么想，是对方的课题，不是我的。更重要的是，这不是"读过就忘"的一时感动：FSRS 会在我即将遗忘的时候把这张卡推回来；和 AI 讨论人际困扰时，它会用苏格拉底式追问验收我是不是真懂了（"你觉得朋友生气，是谁的课题？"）；系统还会把我的掌握度从"知道"一级级带到"会用"。
[P164] [Normal] 
[P165] [Normal] 所以通过知行读书，我得到的是三层收获：
[P166] [Normal] 
[P167] [Normal] 这就是"知行合一"四个字的实感：不是多读了几本书，而是书真的改变了我处理具体事情的方式。如果它对我——一个普通的年轻读者——有效，它就能对微信读书里数以万计同样"读了很多却留不住"的人有效。

[P234] [Heading 2] ### [Heading 2] 5.2  常见问题 FAQ  {font=Times New Roman, size=14.0pt, bold=True}
[P235] [Normal] Q1：在哪里下载安装包？
[P236] [Normal] 答：从 GitHub Releases 页面下载最新的 ZhixingReader-Setup-x.y.z.exe（约 125MB），双击安装即可。
[P237] [Normal] Q2：为什么安装包这么大？
[P238] [Normal] 答：主要来自 Electron 运行时 + sql.js WASM 引擎 + ECharts 图表库，这是 Electron 桌面应用的正常体积。
[P239] [Normal] Q3：支持 macOS / Linux 吗？
[P240] [Normal] 答：当前仅提供 Windows 安装包。macOS / Linux 需要克隆仓库后自行构建（npm install && npm run package），欢迎贡献跨平台打包配置。
[P241] [Normal] Q4：如何更新到新版本？
[P242] [Normal] 答：应用会通过 GitHub Releases API 自动检查更新并提示；也可以手动到 Releases 页面下载新版安装包覆盖安装，本地数据不会丢失。
[P243] [Normal] Q5：我的数据存在哪里？会上传吗？
[P244] [Normal] 答：所有数据（书架、划线、笔记、卡片、对话记录）都存储在本地 SQLite 数据库（sql.js），不上传任何服务器。应用不包含分析、追踪或广告 SDK。
[P245] [Normal] Q6：如何备份数据？
[P246] [Normal] 答：直接复制本地数据库文件 zhixing.db 即可完整备份；也可以在应用内使用导出功能（笔记导出 Markdown、生词本导出 CSV/Anki）。
[P247] [Normal] Q7：支持离线使用吗？
[P248] [Normal] 答：支持。除微信读书同步和 AI 对话需要联网外，复习、笔记、知识卡片、统计等功能均可离线使用。
[P249] [Normal] Q8：如何连接微信读书？
[P250] [Normal] 答：进入「设置 → 微信读书」，填入微信读书开放平台的 API Key，点击「测试连接」，成功后点击「同步书架」。
[P251] [Normal] Q9：同步失败怎么办？
[P252] [Normal] 答：按顺序排查：1) 检查 API Key 是否有效、是否过期；2) 检查网络连接；3) 是否触发了微信读书 API 频率限制（稍后重试）；4) 在设置页点击「立即同步」手动触发。
[P253] [Normal] Q10：多久自动同步一次？
[P254] [Normal] 答：默认每 15 分钟自动同步一次，可在设置中调整为 15 / 30 / 60 分钟，也可随时手动同步。同步为增量模式，不会重复拉取全量数据。
[P255] [Normal] Q11：AI 对话需要自己的 API Key 吗？
[P256] [Normal] 答：需要。进入「设置 → AI 配置」填入你的 AI 服务商 API Key，支持火山引擎、DeepSeek、OpenAI、Anthropic、Moonshot 等。Key 加密保存在本地，请求直连 AI 服务商，不经过任何中转服务器。
[P257] [Normal] Q12：什么是「深度思考」模式？
[P258] [Normal] 答：开启后会展示 AI 的推理过程（支持 DeepSeek R1 reasoning_content、OpenAI reasoning、Claude thinking 三种格式），适合需要看推理链的深度学习场景。
[P259] [Normal] Q13：AI 对话和普通聊天机器人有什么区别？
[P260] [Normal] 答：知行读书的智能体会根据你的意图自动切换教学策略：直接回答（知识查询）、苏格拉底追问（深度讨论）、费曼复述（教学实践）。同时自动注入 5 维上下文（书籍内容 / 知识卡片 / 记忆 / 方法论 / 用户画像），回答基于你真实读过的内容。
[P261] [Normal] Q14：一次对话消耗多少 Token？
[P262] [Normal] 答：约 500–2000 tokens（取决于上下文和回复长度）。可在「Token 监控」页面查看各服务商、各功能的详细用量统计。
[P263] [Normal] Q15：复习算法是什么？和 Anki 一样吗？
[P264] [Normal] 答：采用 FSRS v5 算法（基于 ts-fsrs 5.4.1，open-spaced-repetition 官方实现），与 Anki 23.10+ 同源，19 组标准权重的 DSR 模型。卡片数据结构与 Anki 兼容，可导出到 Anki。
[P265] [Normal] Q16：复习评分怎么选？
[P266] [Normal] 答：1 忘记（完全想不起来）/ 2 困难（吃力）/ 3 良好（正常想起，大多数情况）/ 4 简单（毫不费力）。算法会根据评分自动调整下次复习时间。
[P267] [Normal] Q17：生词本怎么用？
[P268] [Normal] 答：阅读英文内容时选中单词点击「添加到生词本」，系统自动查询释义（内置约 8 万词的本地 ECDICT 词典，离线可查）。生词按独立的记忆算法调度复习，支持导出 CSV / Anki 格式。
[P269] [Normal] Q18：应用启动后白屏 / 打不开怎么办？
[P270] [Normal] 答：1) 完全退出后重新启动；2) 检查杀毒软件是否拦截了应用；3) 重新安装最新版本；4) 仍有问题请到 GitHub Issues 反馈，附上系统版本和复现步骤。
[P271] [Normal] Q19：如何反馈 Bug 或提功能建议？
[P272] [Normal] 答：到 GitHub Issues 提交，描述清楚：使用版本、操作步骤、预期行为、实际行为（最好附截图）。
[P273] [Normal] Q20：如何参与贡献？
[P274] [Normal] 答：阅读 CONTRIBUTING.md 了解开发环境搭建和 PR 流程，提交前确保 npm run verify 全绿（lint / typecheck / test / build）。
