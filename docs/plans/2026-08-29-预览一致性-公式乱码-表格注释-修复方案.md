# 预览一致性 × 公式乱码 × 表格注释 × 图表 Skill 化 —— 修复方案与调研归档（2026-08-29）

> 触发：用户对示例文章（agent 架构）双链路产物提出 4 点问题：
> ① MD 预览与 Word 真实效果不一致 ② 表格注释要在表格下面 ③ 流程图要用本目录 skill 生成 ④ 数学公式乱码。

## 一、问题根因定位

| # | 问题 | 根因 |
|---|------|------|
| 1 | 公式乱码 | `md_to_word.py` 自研 LaTeX→OMML 解析器（tokenize/parse_group/ast_to_elem）只支持 frac/sqrt/上下标/希腊字母映射，`\mathbf`/`\arg`/`\le`/`\top` 等命令原样输出为字面文本 |
| 2 | 行内公式不渲染 | `md_to_word` 只处理 `$$...$$` 行间公式，行内 `$N$`、`$O(N)$` 无处理 → Word 显示字面 `$...$`；预览（KaTeX）却正常渲染 → 预览与 Word 不一致的直接来源之一 |
| 3 | 表格注释位置 | `word_template_engine.add_table` 把 `> **表1：**` 标题渲染在表格**上方**（用户要求下方）；且表格后的 `> 注：` 表注未被识别 |
| 4 | 图没用 skill | `diagram_render.py` 的 super-diagram 脚本路径硬编码 `c:\Users\Lenovo\...`，本机是 Administrator → `_find_super_script()` 返回 None，图表渲染**静默失败**；且 PNG 导出依赖 playwright（未装） |
| 5 | 预览不一致（全局） | Preview 用 markdown-it 默认样式（GitHub 风格全框线表格/灰底表头/标题下划线），与 Word 模板引擎（三线表/黑体标题/注释）无共享样式 |

## 二、业界调研结论（AI 办公软件怎么处理）

### 公式转换（LaTeX → Word 原生公式）
主流开源路线**完全一致**，均为 **`latex2mathml`（LaTeX→MathML）+ Office 官方 `MML2OMML.XSL`（MathML→OMML）**：
- tex2word（PyPI，2025 活跃）`[mathml]` extra 即此路线；Pandoc/texmath 为开源参考但丢公式编号、复杂公式输出原始 LaTeX
- formulas-in-word（GitHub renderlex）同款：`Image→LaTeX→MathML→OMML→Word native equation`
- CSDN ChatGPT 公式转 Word 避坑文：推荐 latex2mathml + pandoc/MML2OMML.XSL

**结论**：替换自研解析器为标准链路（无外部进程、纯 Python、覆盖完整语法）。

### 文档生成范式
- Notion/飞书/腾讯文档：文档本身 WYSIWYG 渲染，AI 输出直接落块，导出 Word 从渲染树生成 → **"预览即最终效果"**
- 我们是 MD 中间态 + 双渲染器（Word 引擎 / KaTeX 预览），要做到预览贴近 Word，需**共享"语义→样式"映射**：三线表、标题层级、注释样式、公式（KaTeX ≈ Cambria Math）

## 三、修复实施清单

### 1. 公式链路（word_template_engine.py + md_to_word.py）
- 新增 `latex_to_omml()`：`latex2mathml` → MathML → `MML2OMML.XSL`（XSLT）→ `m:oMath`；XSL 路径自动探测（`MML2OMML_XSL` 环境变量 → Office16/15 常见路径）
- **坑**：XSLT 输出根可能就是 `m:oMath`（`find('.//')` 不匹配根元素 → 返回 None → 静默兜底）→ 修复：`if root.tag == oMath: return root`
- 预处理：`\arg\max` → `\argmax`（latex2mathml 原生支持 `\argmax` 输出 `movablelimits` 运算符；`\operatorname` 不支持）
- 行内公式：`_add_inline_runs` 正则 `(\*\*.+?\*\*|\$[^$\n]+\$)` 拆出 `$...$` → 插入 oMath（`para._p.append`）
- 表格单元格也走 `_add_inline_runs`（表 2 的 `$O(N)$` 不再字面）
- 自研解析器保留为兜底（latex2mathml/XSL 缺失时降级不崩）

### 2. 表格注释位置
- `add_table`：标题 `add_caption` 移到表格**之后**；表注 `note` 在标题后（`add_annotation`）
- `md_to_word`：表格后 `> 注：xxx` → `note` 参数；caption 去 `**` 残留
- `convert.py`（LaTeX 侧）：BLOCK_QUOTE 引用形式表格标题（`> **表1：**`）→ pending_caption；表格后 `> 注：` → `{\footnotesize 注：...}`（paper/report 两个 assemble 同步）
- 三线表：Word 表格 `Table Grid` 全框线 → 自定义边框（上下 1.5pt 粗线 + 表头下 0.75pt 细线，无竖线），与 booktabs 一致

### 3. 图表 Skill 化
- `diagram_render.py`：super-diagram 脚本路径**自动探测**（环境变量 → `~/.trae-cn/skills` → 兜底）
- 示例文章图 1/图 2 改为 super-diagram 契约（architecture 分层架构 + sequence 消息流转），office.py 管线自动渲染 PNG
- 安装 playwright + chromium（npmmirror 镜像）支撑 PNG 导出

### 4. 预览一致性（web-editor）
- `index.css`：`.markdown-preview` 三线表（上下 2px 粗线 + 表头 1px 细线，无竖线、无灰底表头）、表格居中、标题层级去下划线、blockquote 注释样式
- `Preview.tsx`：新增 `moveTableCaptionBelow()` —— 把表格前 `> **表N：**` 引用块移到表格下方（与 Word 渲染一致）
