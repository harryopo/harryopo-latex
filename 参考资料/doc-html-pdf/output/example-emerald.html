基础组件
第 一 章 · 共 3 章

本示例演示 doc-html-pdf 支持的全部排版组件。段落、表格、引用提示、列表为最常用的基础组件，覆盖绝大多数说明类文档的排版需求。

1.1 表格
组件用途JSON type
段落普通正文paragraph
表格结构化数据table
引用提示重点说明callout
列表条目罗列list
使用提示
引用块（> 开头）在蒸馏时自动转换为 callout；首行带 **加粗标题** 时自动作为提示标题。
注意
warn 变体使用琥珀色，适合强调风险与注意事项。
支持能力
  • Markdown → JSON 蒸馏（含 frontmatter）
  • HTML + PDF 双格式输出
  • 打印样式与 A4 分页
  • 编写 Markdown 源文件
  • 运行 distill.py 蒸馏为 JSON
  • 运行 build.py 生成 HTML 与 PDF

问答与键值
第 三 章 · 共 3 章
输出格式
HTML + PDF（A4）
运行环境
Python 3.10+，依赖 jinja2 / playwright
主题扩展
在 themes/ 下新增 JSON 即可，无需改代码
Q1：如何更换主题？
build.py 使用 --theme 指定主题 ID，例如 --theme slate；批量生成时自动遍历全部主题。
Q2：作者信息如何填写？
在 Markdown 顶部写 YAML frontmatter（author/version/date 等），蒸馏时会自动读取；缺省字段在封面自动隐藏。
Q3：支持哪些 Markdown 语法？
标题、段落、表格、列表、代码块、引用块、frontmatter；连续段落自动合并为一段。
